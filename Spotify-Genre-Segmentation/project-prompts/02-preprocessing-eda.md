# MASTER PROMPT 02 — SONIC ATLAS
## Phase 2: Data Preprocessing, Cleaning & Exploratory Data Analysis (EDA)

### Overview
Build the robust data transformation pipeline, impute or handle missing values, resolve track duplicates across multiple playlists, analyze audio feature distributions, and export cleaned datasets.

### Planned Key Tasks
1. Imputation / handling of missing metadata (5 rows with NA track_name, artist, album).
2. De-duplication strategy for tracks appearing in multiple playlists or genres.
3. Feature distribution analysis (skewness, kurtosis, scaling prerequisites).
4. Audio feature normalization / standardization.
5. Exploratory visualizations: genre-wise feature profiles and distribution plots.
6. Export cleaned dataset to `data/processed/cleaned_spotify_songs.csv`.
