# MASTER PROMPT 01 — SONIC ATLAS
## Phase 1: Project Foundation, Dataset Inspection & Professional Design System

### Overview
Establish the foundational infrastructure for **SONIC ATLAS — Music Intelligence Platform**, a professional music analytics and genre-discovery application built around Spotify song data.

### Phase 1 Objectives
1. **Folder & Repository Architecture**: Maintain a clean, maintainable modular structure separating data, source code, notebooks, models, reports, and tests.
2. **Dataset Verification & Inspection**: Deeply audit `data/raw/spotify_songs.csv` without fabricating or synthesizing mock records.
3. **Core Python Foundation**: Implement `config.py`, `data_loader.py`, and `preprocessing.py` with defensive error handling.
4. **Professional Design System**: Implement dark editorial interface tokens, typography hierarchies (Manrope, Inter, JetBrains Mono), 8px spacing, and restrained green accents (`#55D99A`).
5. **Initial Streamlit Interface**: Deliver an executive landing dashboard presenting verified dataset dimensions, genre distributions, and structured Phase navigation placeholders.
